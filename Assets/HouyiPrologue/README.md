# 《后羿：九日之劫》序章 · 焦土上的弓声

这是当前项目中的一段独立可玩序章，蓝衣角色暂代后羿。无需安装额外插件。

## 运行

在 Unity 中打开 `Assets/HouyiPrologue/Scenes/Houyi_Prologue.unity` 并点击 Play。
也可从菜单 `Tools > Houyi > Open Prologue` 打开。
本场景设为 Build Settings 中第一个启用的场景，原有场景仍保留在列表内。

## 操作

手机端自动启用横屏触控：左下虚拟摇杆移动；右半屏空白处滑动瞄准；右下射击按钮按住蓄力、松手放箭；靠近可交谈的 NPC 或祭坛时显示交互按钮。支持同时移动、转镜头和射击的多指操作。射击手指滑出按钮后松开仍会放箭；触摸被系统取消、切到后台、打开对白或暂停时则取消蓄力，避免误射。

触控界面也提供「继续对白」「暂停/继续」「札记/收起」「重试/重玩」按钮，无需外接键盘。摇杆和动作按钮按屏幕安全区域放置，以避开刘海和系统手势边缘。

在电脑的 Unity Game 窗口中按 **F2** 可切换触控预览，也可勾选角色 `ProloguePlayer` 的 **Preview Touch Controls**。预览时用鼠标拖动摇杆、右侧区域，或按住射击按钮；鼠标只能模拟单指，多指同时操作需真机验证。关闭预览即恢复以下键鼠操作。

| 操作 | 按键 |
| --- | --- |
| 移动 / 疾行 | WASD / 左 Shift |
| 调整镜头与准星 | 按住鼠标右键并移动鼠标 |
| 举弓、蓄力、放箭、收弓 | 按住鼠标左键，松开发箭 |
| 交谈 / 祭坛交互 | 靠近后按 E |
| 继续对白 | E / 空格 |
| 行旅札记 | Tab |
| 暂停 / 继续 | Esc |
| 倒下后重试 / 通关后重玩 | R |

## 流程

1. **枯桑村**：开场文字介绍十日失序的征兆，沿村道找到村老并交谈。
2. **试弓场**：射中三面草靶，熟悉四阶段射箭与准星。
3. **枯井救援**：击退三只炎瘴灾兽，与受困村民交谈。满蓄力一箭击倒灾兽，普通箭需要两次命中。
4. **山脚祭坛**：阅读石碑，对话结束后九轮额外赤日显现，光照转为灾厄色调。
5. **赤日封印**：满蓄力射中悬浮封印，触发结尾对白与序章完成画面。弱箭不能打破封印。

气血耗尽后可从当前任务检查点恢复，已命中的靶子和已击退的灾兽会保留。与 NPC 对话、阅读札记或暂停时不能射箭，灾兽也暂停追击。

## 内容与结构

- `Scripts/PrologueDirector.cs`：任务状态、交互、中文对白、HUD、暂停与重试。
- `Scripts/ProloguePlayer.cs`：第三人称移动、镜头碰撞、准星、旧版移动动画及弓弦音效。
- `Scripts/PrologueTouchControls.cs`：多指输入分配、安全区域内的触控按钮与虚拟摇杆。运行时自动接入现有场景与角色，无需手动重建场景。
- `Scripts/PrologueTarget.cs`：靶子、灾兽追击/伤害、封印命中规则。
- `Editor/HouyiPrologueBuilder.cs`：重建场景和环境的编辑器菜单。
- `Art/`：程序生成的村落环境材质、山体网格，以及天空、太阳与光晕 Shader。
- `Houyi_Player.prefab`：可复用角色预制体；放进其他场景时需绑定任务控制器与相机。

角色沿用 `ArcheryDemo/BlueRobeArcher.prefab`，射箭仍由原 Bip001 骨架 IK 驱动。移动动画来自原项目 `ZY.FBX`。村老、村民与灾兽分别复用原项目的 LaoTou、ShuSheng 和 fox 模型；背景音乐复用 music2。弓弦发射音效由代码生成。

本次完成的是序章玩法原型：环境采用简化几何搭建，尚未制作正式过场动画、角色配音、存档系统和下一章内容。章节末尾“扶桑余烬”仅为后续剧情预告。

## 验证

已在 Unity 2022.3.62f2 中完成真实箭矢碰撞的完整流程检查：三面草靶、三只灾兽、救援与祭坛对白、九日显现、弱箭拒绝/满蓄力破印、结尾，以及死亡检查点恢复。验证使用隔离工程执行，原关卡不需要承担测试改动。
